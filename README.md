📘 MTNA — Matemática e Criatividade
Este projeto é um website desenvolvido como parte do módulo de HTML, CSS e JavaScript. O objetivo foi criar um site simples, funcional e visualmente apelativo, com foco na criatividade e na apresentação de conteúdos relacionados com matemática.

📌 Objetivos do Projeto
Criar um website com várias páginas interligadas

Aplicar conceitos de HTML5 e CSS3

Trabalhar navegação, layout e organização de conteúdo

Utilizar imagens, estilos personalizados e estrutura semântica

Desenvolver um design coerente e responsivo

🧭 Estrutura do Site
O site é composto pelas seguintes páginas:

Início — Página principal com o logótipo e apresentação

Blogue — Secção dedicada a artigos e conteúdos

Galeria — Imagens e elementos visuais

Sobre Mim — Pequena apresentação pessoal

Contactos — Informações de contacto

🎨 Tecnologias Utilizadas
HTML5 — Estrutura das páginas

CSS3 — Estilos, layout, sombras, flexbox, fundo ilustrado

JavaScript (opcional) — Para funcionalidades adicionais no blogue

🖼️ Destaques do Design
Navegação fixa com sombra

Logótipo centralizado

Fundo ilustrado com imagem personalizada

Layout responsivo

Tipografia com sombra para melhor contraste

Secções organizadas e fáceis de navegar

🚀 Como Abrir o Projeto
Fazer download da pasta completa

Abrir o ficheiro indexmtna.html num navegador (Chrome, Edge, Firefox)

Navegar pelas páginas através do menu superior

📚 Notas Finais
Este projeto foi desenvolvido com foco na criatividade e na prática de construção de websites. A identidade visual MTNA combina formas geométricas e cores associadas à matemática e à imaginação.
